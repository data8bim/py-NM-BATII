# py-NM-BATII
py‑NM‑BATII est une extension pyRevit développée pour accélérer et fiabiliser la production BIM dans le cadre du workflow NM‑BATII.
Elle centralise des outils internes destinés à la reprise de plans 2D, la mise en forme, l’automatisation de tâches répétitives et l’amélioration de la qualité des modèles Revit.
